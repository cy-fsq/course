1 变量与数据类型

📖 知识点讲解

变量是存储数据的容器，Python支持多种数据类型：整数(int)、浮点数(float)、字符串(str)、布尔值(bool)。

整数 (int)
x = 10
浮点数 (float)
y = 3.14
字符串 (str)
name = "Python"
布尔值 (bool)
is_active = True

💻 代码示例

# 变量赋值与数据类型 name = "小明" age = 18 height = 1.75 is_student = True print(f"姓名：{name}") print(f"年龄：{age}") print(f"身高：{height}米") print(f"是否学生：{is_student}")

2 条件判断

📖 知识点讲解

条件判断使用 if、elif、else 关键字，让程序根据不同条件执行不同的代码块。

基本语法：
if 条件1: # 条件1为True时执行 elif 条件2: # 条件2为True时执行 else: # 所有条件都不满足时执行

💻 代码示例

# 成绩评级系统 score = 85 if score >= 90: print("成绩等级：A") elif score >= 80: print("成绩等级：B") elif score >= 60: print("成绩等级：C") else: print("成绩等级：D（需补考）")

3 循环结构

📖 知识点讲解

循环用于重复执行代码块。Python有两种循环：for循环（遍历序列）和while循环（条件为真时重复）。

for循环
for i in range(5):
while循环
while i < 5:

💻 代码示例

# for循环：遍历列表 fruits = ["苹果", "香蕉", "橙子"] for fruit in fruits: print(f"我喜欢吃：{fruit}") # while循环：计算累加 total = 0 i = 1 while i <= 5: total += i i += 1 print(f"1+2+3+4+5 = {total}")

4 列表与元组

📖 知识点讲解

列表(list)是可变的有序序列，用方括号表示；元组(tuple)是不可变的有序序列，用圆括号表示。

列表 [可变]
nums = [1, 2, 3]
可以添加、删除、修改元素
元组 [不可变]
coords = (10, 20)
创建后不能修改，更安全

💻 代码示例

# 列表操作 numbers = [1, 2, 3, 4, 5] print(f"原列表：{numbers}") print(f"第一个元素：{numbers[0]}") print(f"最后三个：{numbers[-3:]}") numbers.append(6) print(f"添加6后：{numbers}") # 元组操作 point = (10, 20) print(f"坐标点：{point}") print(f"X坐标：{point[0]}")

5 字典操作

📖 知识点讲解

字典(dict)是一种键值对(key-value)的数据结构，用大括号表示，可以通过键快速访问值。

基本语法
student = {"name": "张三", "age": 18}
通过键访问：student["name"] → "张三"

💻 代码示例

# 字典的创建和访问 student = { "name": "小明", "age": 18, "grade": "高二" } print(f"姓名：{student['name']}") print(f"年龄：{student['age']}") # 添加和修改 student["score"] = 95 student["age"] = 19 print(f"更新后：{student}")

6 函数定义

📖 知识点讲解

函数是组织代码的基本单元，使用def关键字定义。函数可以接收参数，执行特定任务，并返回结果。

函数基本结构
def 函数名(参数): """函数说明文档""" # 函数体 return 结果

💻 代码示例

# 定义计算面积的函数 def calculate_area(width, height): """计算矩形面积""" area = width * height return area # 定义问候函数 def greet(name, greeting="你好"): """带默认参数的问候函数""" return f"{greeting}，{name}！" # 调用函数 result = calculate_area(5, 3) print(f"矩形面积：{result}") print(greet("小明")) print(greet("小红", "早上好"))

7 文件操作

📖 知识点讲解

Python使用open()函数打开文件，使用with语句可以自动关闭文件，推荐使用这种方式。

读文件
with open("file.txt", "r") as f:
写文件
with open("file.txt", "w") as f:
追加内容
with open("file.txt", "a") as f:

💻 代码示例

# 使用StringIO模拟文件操作（浏览器中运行） from io import StringIO # 写入数据 output = StringIO() output.write("第一行数据\n") output.write("第二行数据\n") output.write("第三行数据\n") # 读取数据 output.seek(0) content = output.read() print("文件内容：") print(content) # 按行读取 output.seek(0) for line in output: print(f"读取行: {line.strip()}")
